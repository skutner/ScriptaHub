Hunger, Taboo, and the Civilization That Cannot Say Enough

A hunting band can survive bad luck if food is shared. It can survive an injured hunter if someone else carries more weight. It can survive a weak season if stores are distributed with memory of tomorrow. But the margin is thin. One person taking too much is not merely selfish in the abstract. In a closed winter ecology, excess consumption can reappear as somebody else's missing meal.
